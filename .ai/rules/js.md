# Js

## Regenerate Wayfinder with --with-form
`resources/js/actions` and `resources/js/routes` are gitignored and generated by the Vite plugin, which is configured with `formVariants: true` (vite.config.ts).

Running bare `php artisan wayfinder:generate` silently drops the `.form()` variants and breaks `npm run types:check` with ~19 `TS2339: Property 'form' does not exist` errors across Vue pages. Always use `php artisan wayfinder:generate --with-form`, or just run the Vite build.
